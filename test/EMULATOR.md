# قيادة النظام على المحاكي

تشغيل النظام كاملاً — من شاشة الدخول إلى آخر صفحة، بالأدوار الثلاثة — على
بيانات مصطنعة، بلا حساب حقيقي وبلا أن يُكتب حرف واحد في الإنتاج.

## لماذا لا نجرّب على الإنتاج

كل ضغطة زرّ في النظام الحقيقي تكتب سجلاً حقيقياً: حضور بتاريخ اليوم لموظف
حقيقي، وطلب يصل صندوق مدير حقيقي، وسطر في `auditLog` **لا يُحذف أبداً**
(`allow update, delete: if false`). وقواعد الحضور تمنع عمداً إعادة كتابة
الجلسات المغلقة — فحضور وهمي سُجّل للتجربة لا يُتراجع عنه بسهولة.

أي أن التجربة نفسها كانت تلوّث ما تختبره.

## التشغيل

ثلاث نوافذ طرفية:

**١ — المحاكيان**

```
cd test
export PATH="/opt/homebrew/opt/openjdk/bin:$PATH"
npx firebase emulators:start --only firestore,auth --project seen-hr2
```

**٢ — البذور** (بعد أن يقول المحاكي `All emulators ready`)

```
cd test && node seed-emulator.mjs
```

يُنشئ ثلاثة حسابات وشركة كاملة: فروع وورديات وأنواع إجازات وأسباب استئذان،
وسجلات حضور لأربعة عشر يوماً فيها تأخير وغياب ونسيان بصمة، وخمسة طلبات
بحالات مختلفة. الشاشة الفارغة تُخفي أعطالها، فكل شاشة عليها ما تعرضه.

**٣ — الموقع**

```
python3 -c "
import http.server, socketserver
class H(http.server.SimpleHTTPRequestHandler):
    def end_headers(self):
        self.send_header('Cache-Control','no-store')
        super().end_headers()
socketserver.TCPServer.allow_reuse_address = True
socketserver.TCPServer(('',8791), H).serve_forever()
"
```

⚠️ `no-store` ليس زينة: `python3 -m http.server` لا يرسل ترويسات تخزين،
فيُخزّن كروم وحدات ES ويستمرّ يشغّل نسخة قديمة بعد تعديلك — وتطارد عطلاً
أصلحته أصلاً.

ثم افتح `http://localhost:8791` وفعّل المحاكي مرّة واحدة من الكونسول:

```js
localStorage.setItem('seen-hr:emulator','1'); location.reload();
```

## الحسابات

| الدور | رقم الدخول | كلمة المرور | الاسم |
|---|---|---|---|
| مدير النظام | `0500000001` | `Test12345!` | ريم الأحمد |
| مدير قسم | `0500000002` | `Test12345!` | فهد العتيبي |
| موظف | `0500000003` | `Test12345!` | سالم القحطاني |

كلها مصطنعة وتعيش في المحاكي وحده. لا تُستعمل في أي مكان آخر.

## كيف يُفصَل المحاكي عن الإنتاج

في `js/lib/firebase.js`، بشرطين معاً:

1. `location.hostname` ∈ `localhost` أو `127.0.0.1`
2. العَلَم `seen-hr:emulator` في `localStorage`

النظام منشور على `amf430.github.io` — وهو ليس أياً من الاثنين، فلا يمرّ هذا
الفرع في الإنتاج إطلاقاً. والعَلَم الثاني يمنع أن يتحوّل أي فتح محلي عادي إلى
محاكي بصمت فيظنّ المطوّر أن بياناته اختفت.

⚠️ لا توسّع شرط `hostname`. توسيعه يوجّه بيانات حقيقية إلى خادم وهمي، أو
أسوأ: يوجّه بيانات التجربة إلى الإنتاج.

## الإيقاف

أوقف المحاكي، وامسح العَلَم:

```js
localStorage.removeItem('seen-hr:emulator');
```
