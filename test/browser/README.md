# اختبارات المتصفح

`payroll.js` و `attendance.js` و `photo.js` و `requests.js` تصل كلها إلى
`firebase.js` عبر سلسلة الاستيراد، وهي تجلب الـSDK من gstatic وتُنشئ تطبيق
Firebase وقت الاستيراد نفسه. فلا تُستورد في node، ولا يمكن اختبارها هناك.

وهي في الوقت نفسه أهمّ منطق في النظام: `computePayroll` تحسب خصماً من رواتب
أشخاص، و `buildDailyStatus` تقرّر من هو «متأخر» ومن هو «غائب».

فتُختبر هنا، في متصفح حقيقي، على الوحدات نفسها التي تعمل في النظام — لا على
نسخة منها ولا على محاكاة.

## التشغيل

من جذر المستودع:

```
python3 -m http.server 8777
```

ثم افتح:

```
http://localhost:8777/test/browser/suite.html
```

النتيجة تظهر أسفل الصفحة: عدد الناجح والفاشل، وكل اختبار فاشل معه ما تُوقّع
وما جاء. وتُنشر كذلك على `window.__RESULTS` للقراءة الآلية، و `window.__DONE`
يصير `true` عند الانتهاء.

⚠️ لا بدّ من خادم — فتح الملف بـ `file://` يمنع استيراد الوحدات.

## ما تغطّيه

| القسم | ماذا يثبت |
|---|---|
| ١ | قيمة اليوم والساعة، وأن الحضور الكامل بلا خصم |
| ٢ | التأخير والخروج المبكر وخصمهما بالدقيقة |
| ٣ | الاستئذان **المعتمد وحده** يُعفي — والمعلَّق والمرفوض لا، ونوعه يقرّر أي دقائق تُعفى |
| ٤ | الغياب، والإجازة المدفوعة، والإجازة بدون راتب |
| ٥ | حدود المسير: الصافي لا يصير سالباً، ومن باشر داخل الدورة لا يُحاسب على ما قبله، والأدمن خارج المسير، ودقائق السماح |
| ٦ | الحالة اليومية: حاضر · متأخر · غائب · إجازة · نسيان بصمة، وأيام الراحة غير محسوبة |
| ٧ | نافذة الاستئذان على الحالة اليومية — وسم «بدون عذر» بعد إغلاقها |
| ٨ | الجلسات المتعددة، والشكل القديم `checkIn/checkOut`، وقصّ الجلسة المفتوحة |
| ٩ | ضغط صورة إثبات الموقع وبقاؤها دون حدّ القاعدة |
