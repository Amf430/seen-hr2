# الاختبارات

مجموعتان:

| الأمر | ما يفحصه | يحتاج Java |
|---|---|---|
| `npm run test:org` | دوال الهيكل التنظيمي | لا |
| `npm run test:docs` | تواريخ انتهاء المستندات والتنبيه عليها | لا |
| `npm run test:nav` | بقاء الصفحة في العنوان بعد التحديث | لا |
| `npm run test:notif` | مركز الإشعارات واستقرار معرّفاتها | لا |
| `npm run test:bio` | تمييز إلغاء الموظف من عجز الجهاز | لا |
| `npm run test:perm` | نافذة الاستئذان — ثلاثة أيام ثم تُغلق | لا |
| `npm run test:core` | الورديات والفروع وصلاحيات الاعتماد ودورة الرواتب | لا |
| `npm run test:pure` | السبعة أعلاه معاً — أجزاء من الثانية | لا |
| `npm run test:rules` | `firestore.rules` على المحاكي | نعم |
| `npm test` | الكل بالترتيب | نعم |
| `test/browser/suite.html` | المسير والحالة اليومية وضغط الصورة | لا — يحتاج متصفحاً |

⚠️ `payroll.js` و `attendance.js` تصلان `firebase.js` عبر سلسلة الاستيراد، وهي
تجلب الـSDK من gstatic وقت الاستيراد — فلا تعملان في node مهما فعلت. تُختبران
في المتصفح وحده: انظر [`browser/README.md`](browser/README.md).

اختبار القواعد يجرّب الهجمات الحقيقية والعمليات المشروعة معاً — لأن قاعدة ترفض
تسجيل حضور صحيح أسوأ من قاعدة متساهلة.

    cd test && npm install && npm test

يحتاج Java (المحاكي يعمل على JVM):

    brew install openjdk
    export PATH="/opt/homebrew/opt/openjdk/bin:$PATH"

⚠️ حزمة openjdk من Homebrew ‏«keg-only»: تُثبَّت ولا تُوضع على `PATH`. فوجود
`/usr/bin/java` لا يعني شيئاً — هو كعب macOS الذي يطبع «Unable to locate a Java
Runtime». لا بدّ من سطر `export` أعلاه في كل صدفة جديدة، وإلا فشل المحاكي برسالة
تبدو كأن Java غير مثبَّتة أصلاً.

آخر تشغيل: **170 اختبار قواعد + 220 اختبار خالص + 75 اختبار متصفح
(22 هيكل · 30 مستندات · 22 تنقّل · 26 إشعارات · 27 بصمة · 16 نافذة استئذان ·
77 قلب حاسب) — 465 اختباراً، كلها ناجحة.**

⚠️ التواريخ في الاختبارات نسبية (`dRel(n)`) لا مكتوبة بنصّها. قاعدتا `leaveOk`
و `permOk` تقارنان التاريخ بوقت الخادم، فتاريخ ثابت يجعل المجموعة تنجح اليوم
وتفشل بعد شهر بلا أن يتغيّر شيء في القواعد.
